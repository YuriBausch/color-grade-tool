Crash tests du match

Chaque cas passe un rush (Rec.709, S-Log3 ou LogC3) dans le vrai moteur de index.html, avec comme référence soit l'image finale du même plan (cas idéal), soit celle d'un autre plan (cas réel). Le résultat est comparé à l'image finale du film. ΔE zones : écart des couleurs moyennes ombres / tons moyens / lumières. ΔE pixel : écart moyen pixel à pixel, seulement sur les plans alignés (pas de décor VFX).

Données : lancer d'abord python tools/fetch_tos.py puis python tools/make_examples.py. Images : (CC) Blender Foundation | mango.blender.org.
